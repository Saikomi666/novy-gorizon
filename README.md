# НОВЫЙ ГОРИЗОНТ — сайт анкеты

В папке уже лежит `background.mp4` — загруженное вами видео. Оно используется как полноэкранный зацикленный фон без пауз.

## Что есть

- полноэкранное autoplay/muted/loop видео;
- сиренево-фиолетово-розовая палитра;
- пиксельная сетка/шум и Pixelify Sans;
- шапка «НОВЫЙ ГОРИЗОНТ» с белой четырёхконечной звездой;
- большая кнопка «ПРИСОЕДИНИТЬСЯ К СВОИМ»;
- длинная анкета без `maxlength` для текстовых полей;
- два изображения персонажа;
- после отправки анкета считается финальной;
- Google Apps Script автоматически создаёт лист «Анкеты», добавляет каждую анкету новой строкой и сохраняет изображения в Google Drive.

## Подключение Google Таблицы

1. Создайте Google Таблицу.
2. Откройте **Расширения → Apps Script**.
3. Скопируйте содержимое `google-apps-script.gs`.
4. Вставьте ID таблицы вместо `PASTE_YOUR_GOOGLE_SHEET_ID_HERE`.
5. Разверните как **Веб-приложение**:
   - выполнять от имени: **ваш аккаунт**;
   - доступ: **все**.
6. Скопируйте URL развёртывания.
7. В `script.js` замените:
   `PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE`
   на этот URL.
8. Откройте `index.html` через хостинг/сервер.

Важно: для реальной работы Google Apps Script лучше разместить сайт на обычном HTTPS-хостинге. Сам `index.html` можно использовать с GitHub Pages, Netlify, Vercel или другим статическим хостингом.

## Важный момент с изображениями

Скрипт сжимает изображения в браузере перед отправкой. PNG с прозрачностью старается сохранить как PNG. Это уменьшает размер отправки в Google Apps Script.

## Что можно поменять

В `styles.css` можно менять оттенки, размер текста, степень затемнения видео и пиксельный эффект.

В `index.html` можно менять тексты, порядок вопросов и подписи.

В `script.js` находится только адрес Google Apps Script — больше ничего для подключения таблицы менять не нужно.
